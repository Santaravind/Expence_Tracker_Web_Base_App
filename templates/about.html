About The Project

Smart Financial Management Made Simple

ExpenseFlow was built as a modern, reliable, full-stack expense tracking solution using Python Flask, SQLite, and modern CSS.

Our Mission

Many individuals struggle to track where their monthly paychecks go. Complex spreadsheets are tedious to update on mobile, and third-party apps often sell user data. ExpenseFlow bridges this gap with an intuitive interface, 100% private database storage, and automated visual monthly breakdowns.

Architecture & Tech Stack

Flask 3.x Backend

Clean, modular Python backend with session-based authentication, route guarding, and parameterized SQL queries.

SQLite 3 Database

Reliable local embedded SQL storage with relational user and expense schemas, automatic indexing, and instant migrations.

Chart.js Analytics

Interactive client-side data visualizations with responsive canvas rendering for category donuts, trend lines, and bars.

Built With Security in Mind

Password security via Werkzeug PBKDF2 hashing, user-isolated session cookies, and protection against SQL injection.
